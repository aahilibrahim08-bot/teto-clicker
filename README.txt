Teto Clicker - build files

1. Make a free GitHub account, create a new PUBLIC repository.
2. Upload everything in this folder (keep the folder structure, including .github/workflows/build.yml).
3. Open the repository's Actions tab. The build starts by itself (or press "Run workflow").
4. After ~5-15 minutes, open the finished run and download:
   - TetoClicker-APK  -> app-debug.apk  (install on Android)
   - TetoClicker-IPA  -> TetoClicker-unsigned.ipa  (jailbroken iPhone)
